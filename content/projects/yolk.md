> ⚠️ This project is in early development.

[**Yolk**](https://github.com/nilsiker/yolk) is an opinionated Godot C# game template using Chickensoft architecture and packages.

![a pixelated egg yolk](/img/yolk.png)

The objective is to provide Godot developers with an easy-to-understand template, including implementations for common chores such as:

* Starting/saving/loading games
* Level loading and streaming
* User settings such as keybindings, display and audio settings

The project also includes a simple game to showcase the features of the template.
